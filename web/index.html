↗ WHAT RUNS

Real validation, real sources

The official version-matched validator checks OpenCore’s schema and semantics. Additional rules compare selected desktop families, firmware settings, and macOS targets with documented guidance.

↳ WHAT DOESN’T

The bits outside the plist

We can’t inspect your actual EFI files, BIOS, ACPI contents, USB wiring, or boot logs. Unrecognized hardware is marked as a gap, never quietly counted as a pass.
