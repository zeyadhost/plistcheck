+ In the report

The official validator checks OpenCore 1.0.8 schema and semantics. Additional rules cover selected desktop and Intel laptop families, reported firmware settings, and macOS targets.

− Outside the config

EFI files, actual BIOS state, ACPI contents, USB wiring, and boot logs need separate review. Unrecognized hardware stays a visible gap, never a quiet pass.
